# RedNote Travel Style Reference

## Core Positioning

This skill writes Xiaohongshu-style Chinese travel copy for destination recommendations and travel agency soft promotion. The copy should feel like a gentle travel note first and a commercial post second.

The default voice is:

- Warm and visual.
- Softly emotional.
- Short and easy to scan.
- Credible and restrained.
- Suitable for France or Europe travel agency accounts.

## Template 1: Single Destination Slow-Travel Post

Use this when the user gives one place, such as Auxerre.

Structure:

```text
[Emoji] 逃离[城市]｜这个[目的地类型]也太治愈了！

在[城市/生活状态]待久了，总会想离开一下。
我找到了刚刚好的地方：[目的地]

[交通/抵达方式，如果用户提供]
[路上或抵达后的画面感]

[老城/河畔/教堂/小巷/野餐/森林等亮点]
不用赶行程，只是慢慢待着。

为什么推荐

✔️ [理由一]
✔️ [理由二]
✔️ [理由三]

为什么适合交给旅行社安排 / 为什么选我们

✔️ [用户提供的真实服务或资质]
✔️ [用户提供的真实服务或资质]
✔️ [泛化的省心服务，不编造具体承诺]

[柔和结尾 CTA]

[Hashtags]
```

Style notes:

- Begin with a city escape or emotional reset.
- Use "刚刚好", "慢下来", "放松", "治愈", "不用赶行程" when appropriate.
- If transport duration is not provided, do not invent it.
- If agency credentials are not provided, do not create them.

## Template 2: Multi-Attraction Reasons Post

Use this when the user gives a region or destination plus several attractions, such as Loire Valley.

Structure:

```text
[Emoji] 春天来了！给你 N 个要去[目的地]的理由

[Mood emoji line, optional]

如果说[熟悉地点]是[形容]，那[目的地]就是一种更[安静/缓慢/生活感]的美。

这一次，想带你看看一个更“生活感”的[地区/国家]👇

[Emoji] [景点一]：
[一句画面感描述，不写成百科介绍]

[Emoji] [景点二]：
[一句体验感描述]

[Emoji] [景点三]：
[一句感官描述]

[继续列出用户给出的景点]

有时候旅行不需要太多安排，只要在一个对的地方，慢下来就好。

而[目的地]，就是那种你会不自觉放轻脚步的地方。

[可选旅行社软植入]

[Hashtags]
```

Style notes:

- Each attraction gets a compact paragraph.
- Focus on feeling and scene, not encyclopedic facts.
- Keep the list rhythm consistent.
- When the user provides six attractions, use "六个理由"; otherwise match the actual number.

## Agency Soft-Promo Placement

Use agency promotion as a quiet service bridge, not a hard interruption.

Good patterns:

```text
如果你也想把这趟小旅行安排得更省心，
可以把交通、门票和路线一起交给我们规划。
你只需要负责慢慢走、慢慢看。
```

```text
适合想轻松出发、不想自己反复查路线的人。
我们可以根据你的时间和偏好，帮你把一日游安排得更顺。
```

If the user gives specific credentials, preserve them:

```text
✔️ IATA认证
✔️ APST会员
✔️ 20+年经验
```

Do not invent credentials.

## Title Patterns

- `🌿 逃离巴黎｜这个法式小城也太治愈了！`
- `🌷春天来了！给你六个要去卢瓦河谷的理由`
- `周末想离开巴黎？这个小众目的地刚刚好`
- `不赶行程的一天，才是法国旅行的松弛感`
- `这个法国小城，适合把时间慢慢还给自己`

## Hashtag Rules

Generate 8-12 hashtags by default. Mix:

- Destination: `#欧塞尔`, `#卢瓦河谷`, `#法国`
- Region/travel type: `#法国旅游`, `#欧洲旅游`, `#法国一日游`
- Mood: `#治愈系旅行`, `#慢旅行`, `#春日出游`
- Audience: `#留学生`, `#周末去哪儿`
- Discovery: `#小众目的地旅行`, `#探索世界进行时`

Avoid irrelevant viral tags.

## Quality Checklist

Before finalizing:

- Does each version feel like a Xiaohongshu note, not a brochure?
- Are the three versions meaningfully different?
- Are unsupported facts removed or clearly generalized?
- Is the agency placement natural and credible?
- Are the hashtags specific enough to the destination and audience?
